工作流与可信判分

规则路由分配通用、协调、预习、学习、复习任务，角色内再决定工具调用。普通答疑与正式测验隔离，仅依据服务端核验结果更新掌握度与错题。

MCP 与工具边界

外部 MCP 工具与教材查询、判题统一管理；通过参数 Schema、角色白名单、联网授权与单轮调用上限约束执行，异常以可识别结果返回。

断连后的状态处理

请求取消贯通 SSE、Agent、模型与 MCP 调用，释放会话队列，保留已完成判分，并隔离不同请求的执行状态。

记忆与教材可追溯

长期事实保留原文引文、位置、哈希及来源会话，更正时保留历史；教材生成经结构校验与原文复核后发布快照，失败保留旧版。

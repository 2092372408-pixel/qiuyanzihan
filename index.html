AI APPLICATION / EDUCATION2026.03 — 至今

EduPilot

GitHub · 私有仓库

面向编程学习的教学 Agent 平台

独立主导需求、Agent 架构与全栈实现，把教材学习、在线 Python 编程、服务端判题与教学反馈串联起来。项目已用于厦门大学信息学院 2 个教学班。

  • 可执行的学习过程。浏览器内编辑、试运行与判题；把题目、代码和错误输出接入 AI 答疑，以核验成绩更新错题与知识点状态。
  • 有边界的教学编排。基于 LangGraph 路由通用、协调、预习、学习、复习五类角色，使用工具白名单控制调用；普通问答与正式检测分离。
  • 教材检索与长期记忆。支持 6 类教材，结合 BM25、向量召回与 RRF 融合；通过信息信号门控和摘要复用减少重复记忆维护。

验证记录2026.10 固定 60 轮合成对话维护测试：维护模型调用由 32 次降至 12 次，减少 62.5%。

AI FOR SCIENCE / DATA ENGINEERING2026.06 — 至今

科研文献抽取与组合图处理

层状正极科学知识抽取 · 独立负责文本与图像处理

围绕科研文献中“信息散、流程长、图文难关联”的问题，构建 Python 与 LLM 驱动的结构化抽取流程，保留原文、样本身份和图像来源。

  • 从错误样本改进抽取。通过“先锁定流程、再补齐条件”处理合成步骤遗漏，合成路径提取准确率由 34.2% 提升至 97.5%；400 篇人工复核中，最终产物抽取准确率为 98.5%。
  • 让事实与来源对应。以冻结样本注册表贯通产物、合成、性能与形貌抽取，校验来源及缓存身份；100 篇冻结输入的离线重导出中，370 个样本、912 条事实无身份错配，另隔离 1 个待复核样本。
  • 图文数据与组合图拆分。完成覆盖 2,689 个唯一 DOI、32,614 个可读图片文件的清点与索引；接入候选框检测、人工审核裁图和 PDF 区域补图，在 3 篇真实文献上复现 10 张子图处理。
